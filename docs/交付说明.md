# Presence 商品选购应用交付说明

以海外消费者为目标，完成了一个可交互的英文生活方式商店。技术栈为 React 19 + TypeScript + Vite，从空项目实现，没有使用网站或商城模板。

核心流程：商品浏览 → 搜索 / 分类 / 筛选 / 排序 → 详情与颜色选择 → 加入购物车 → 调整数量或删除 → 演示结算。另有收藏、三币种显示、包邮进度和浏览器本地保存。

## 实际验证

- 生产构建与 TypeScript 检查通过。
- 6 项购物车业务自动化测试通过，覆盖颜色合并、库存共用、无效输入、删除、包邮门槛、固定汇率。
- Chrome 浏览器端到端验证通过，覆盖搜索和空结果、分类、排序、收藏、颜色选择、加购、数量调整、总价、刷新恢复、结算、手机导航、删除、存储异常恢复。
- 检查了 360 / 390 / 768 / 1440 px 布局，无横向溢出；商品图片全部加载成功，无浏览器脚本错误。
- 浏览器报告见同目录 `browser-validation.json`；桌面、手机与购物车截图见 PNG 文件。

## 演示录屏

- `desktop-demo.webm`：约 73 秒，展示桌面商品浏览、分类、搜索、详情、颜色与数量、购物车、包邮、刷新恢复和演示结算。
- `mobile-demo.webm`：约 65 秒，展示手机导航、商品浏览、收藏、详情、数量调整、刷新恢复、演示结算与币种切换。
- 两段合计约 2 分 18 秒，无配音，内容为浏览器中的真实操作。

## 主要取舍与已知边界

优先完成选购主流程与响应式体验。未实现后端、登录、真实支付或真实订单。商品数据、评分和库存为模拟值；颜色共用商品示意照片。币种使用固定演示汇率，未计算税费和关税；localStorage 不支持跨设备或多标签页实时同步。未声称完成真实手机硬件或 Safari / Firefox 测试。

仓库根目录中的 `README.md` 包含启动、构建、测试、部署方式与完整边界说明。公开仓库不包含 `node_modules`、构建产物或本地部署身份配置。
